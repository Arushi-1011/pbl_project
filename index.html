Speech Therapy Assistant

An AI-powered system that automatically detects dysarthria from voice recordings and helps patients with personalized speech therapy — making assessment faster, objective, and accessible to everyone.

Problem Statement

Dysarthria is a speech disorder caused by brain-related conditions like Parkinson's disease, stroke, and cerebral palsy. It makes speech slurred, slow, or unclear. Currently, doctors assess it manually by listening — which is subjective, expensive, and not available in rural areas. Many patients don't get timely help due to a shortage of trained speech therapists. Existing digital tools mainly classify speech but do not provide personalized therapy support. There is a need for an intelligent system that can automatically detect dysarthria and help patients with customized feedback and exercises.

Literature Review / Market Research

  • Baevski et al. (2020) — Used Wav2Vec2, a deep learning model. Very powerful but acts like a black box and needs heavy computing infrastructure.
  • Zakariah et al. (2022) — Used MFCC with deep neural networks. Works well for detection but gives no therapy guidance.
  • Moran et al. (2016) — Used BLSTM model for dysarthria detection but only achieved 80% accuracy — not reliable enough for clinical use.
  • Constant Therapy App — Provides exercises assigned by therapists manually. Not AI-driven and requires a specialist to set up.
  • Speechify / LSVT App — Gives real-time voice feedback but is not designed specifically for dysarthria patients.

Research Gap / Innovation

  • Most dysarthria tools only detect or classify speech — they don't suggest what the patient should do next.
  • Detection and therapy are handled separately — there is no single unified system for both.
  • Exercises provided by existing apps are the same for everyone — not based on how the individual patient speaks.
  • This project builds one system that detects dysarthria from voice and also gives the patient personalized therapy suggestions.
  • It uses the TORGO dataset — real voice recordings of dysarthric patients — to train and test the system.

System Methodology

Dataset

  • • TORGO Dataset — real voice recordings of dysarthric and healthy speakers
  • • 2,104 voice samples → 4,208 after augmentation
  • • Dysarthric speakers: 1,569 samples
  • • Healthy speakers: 535 samples
  • • Audio cleaned: silence removed, standardized to 16 kHz
  • • Each clip cut to 2 seconds for consistency
  • • More data created by adding noise, changing speed & pitch

Models / Architecture

  • • 40 MFCC + Delta + Delta-Delta
  • • RMS Energy, ZCR, Spectral Centroid
  • • 246 features → SelectKBest → 150 features
  • • StandardScaler normalization
  • • Models: Random Forest, XGBoost, MLP

Pipeline

Audio → Augment → Extract Features → Select Top 150 → Scale → Train → Evaluate

Tools: librosa · scikit-learn · XGBoost · Audiomentations · Wav2Vec2
